# Homepage motion

`Reveal` is a small adaptation of the [React Bits Animated Content](https://reactbits.dev/animations/animated-content) pattern, using GSAP and IntersectionObserver. It retains visible server-rendered content and adds cleanup and live reduced-motion handling.

`ProductShowcase` adapts the layered account-switching idea from [React Bits Card Swap](https://reactbits.dev/components/card-swap) to the project's real screenshots. It uses native buttons rather than draggable controls, with pause, hover/focus pause, and reduced-motion support.

`HomeTitle` implements a word entrance inspired by [React Bits Split Text](https://reactbits.dev/text-animations/split-text), without changing the original heading or requiring runtime text splitting.

These are focused local implementations, not wholesale copies of the upstream components. Source: https://github.com/DavidHDev/react-bits (MIT). Product images and all copy come from the existing project.
